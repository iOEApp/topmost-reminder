## What groups are for

Groups keep timers of different purposes together. Create a group per project, for example:

- **Kitchen Timers**: soup, steamed eggs, noodles;
- **Work Timers**: meetings, focused work, breaks;
- **Workout Timers**: interval rounds and rest periods;
- **To-do Alarms**: reminders for things that must happen at a set time.

## Creating a group

Click the **new group** button (the plus sign at the end of the tab row) to create a group. Once created you can:

- Name the group to state its purpose;
- Create as many timers as you need inside the group;
- Switch freely between groups — timers in each group run independently.

## Multi-task timing

Every timer in a group runs and alerts independently, so you can:

- Manage and monitor multiple timer projects and events at the same time;
- Run countdowns, timers, stopwatches and alarms across different groups simultaneously;
- Keep on top of every item's progress even when things get busy.

## Note

Groups are not included in the free version. The full version supports groups with unlimited timers — see the [version information](/#versions) on the home page.
